# Code of conduct

## Our commitment

We commit to a collaborative environment where contributors can question assumptions, report mistakes, and review security-sensitive work without harassment or retaliation.

## Expected behavior

- Discuss code and evidence, not personal attributes.
- Give specific, actionable review feedback.
- Credit datasets, specifications, tools, and contributors.
- Handle operational logs, vulnerabilities, and team credentials privately.
- State limitations honestly; do not inflate benchmark or coverage claims.
- Respect hackathon rules, licenses, and repository access controls.

## Unacceptable behavior

Harassment, discrimination, threats, disclosure of private information, unauthorized testing, plagiarism, fabricated evidence, and intentional sabotage are not acceptable.

Repository owners may remove content, revoke access, or escalate serious incidents to the institution or hackathon organizers. Report conduct concerns privately to a repository owner.
