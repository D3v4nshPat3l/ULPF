Integrity

            
Every event carries a fingerprint over its own canonical form plus a link to its predecessor, and the chain is anchored by Ed25519-signed checkpoints. Verification re-hashes the retained window and walks the links.

          

        


        

          

            
Verify the chain

            

              

                Recomputes each event's fingerprint from its content and checks that every
                prev_event link matches the event before it.
              

              

              

            

          


          

            
Tamper test
alters the retained copy only

            

              

                Rewrites one attribute on one retained event, then verify again. The vault is
                append-only and is not touched, so the original bytes stay retrievable and
                provably different from the altered event.
              

              

                
                
                
              

              

              

            

          

        


        

          
Check a proof
paste one issued anywhere

          

            

              A proof carries the signed checkpoint it was made against, so it can be
              checked long after the log has moved on. The signature is verified against
              this collector's public key; altering the proof or the checkpoint inside it
              fails here.
